# Generate License File

Generate License File

## Usage

``` r
License(path, type = "mit")
```

## Arguments

- path:

  Character string. Project path.

- type:

  Character string. License type. Available values include `"mit"` and
  `"gpl3"`.

## Value

Called for its side effects; the value is not meaningful.
