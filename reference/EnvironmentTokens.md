# Set Tokens

Set Tokens

## Usage

``` r
EnvironmentTokens(tokens)
```

## Arguments

- tokens:

  Named vector of tokens.

## Value

Returns vector of secret tokens.

``` r
if (FALSE) { # \dontrun{
```
