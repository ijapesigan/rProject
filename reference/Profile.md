# Setup `.Rprofile`

Setup `.Rprofile`

## Usage

``` r
Profile(path, project)
```

## Arguments

- path:

  Character string. Project path.

- project:

  Character string. Project name.

## Value

Called for its side effects; the value is not meaningful.
