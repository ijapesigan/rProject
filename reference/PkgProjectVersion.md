# Install Project Packages with Specific Version

Install Project Packages with Specific Version

## Usage

``` r
PkgProjectVersion(path, pkg, ver)
```

## Arguments

- path:

  Character string. Project path.

- pkg:

  Character vector. R packages.

- ver:

  Character vector. Version.

## Value

Called for its side effects; the value is not meaningful.
