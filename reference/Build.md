# Build Package

Build Package

## Usage

``` r
Build(path, vignettes = FALSE, dependencies = FALSE)
```

## Arguments

- path:

  Character string. Project path.

- vignettes:

  Logical. Build vignettes.

- dependencies:

  Logical. Install package dependencies.

## Value

Called for its side effects; the value is not meaningful.
