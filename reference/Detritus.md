# Create `detritus/tex/tex-fig-*`

Create `detritus/tex/tex-fig-*`

## Usage

``` r
Detritus(path)
```

## Arguments

- path:

  Character string. Project path.

## Value

Returns a list with the detritus folder and the paths of the `.tex`
files.
