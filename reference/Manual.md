# Package Manual

Package Manual

## Usage

``` r
Manual(path, project)
```

## Arguments

- path:

  Character string. Project path.

- project:

  Character string. Project name.

## Value

Called for its side effects; the value is not meaningful.

## Examples

``` r
if (FALSE) { # \dontrun{
Manual(path = getwd(), project = "myProject")
} # }
```
